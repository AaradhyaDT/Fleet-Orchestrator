## 2. Certified Core Infrastructure

### A. Antigravity 2.0 Native Task Handoff Protocol
- One-shot tasks dispatched via `.\fleet.bat run-task --spec "..." --auto-tier <tier>` stream real-time execution milestones directly into the Antigravity 2.0 HTML Auxiliary Pane (**Background Tasks** tab).
- Preserves the Context Firebreak (`INV-CTX-FIREBREAK`, parent context <5,000 tokens) with **$0.00** LLM polling cost and reactive resume on completion.
- Milestone sequence: `[CLAIMED]` $\to$ `[WORKTREE]` $\to$ `[EXEC]` $\to$ `[PROGRESS]` $\to$ `[CHECKPOINT]` $\to$ `[COMPLETED]`.

### B. Tier-Aware Timeout Floor Escalation (`INV-TIER-FLOOR`)
- The SLM router (`tools/fast_intent_router.py`) dynamically computes execution duration (`time_allocation`).
- The CLI (`tools/unified_fleet_cli.py`) enforces minimum timeout floors when `--auto-tier` is passed, preventing premature timeout kills:
  - `efficiency`: Minimum 120s ceiling
  - `balance`: Minimum 300s ceiling
  - `intelligence`: Minimum 600s ceiling
- Keyword routing added for documentation tasks (`docstring`, `jsdoc`, `typehint`, `type annotation`, `add comments`) mapped to `T2_MEDIUM` (90s duration, ~198s ceiling).
