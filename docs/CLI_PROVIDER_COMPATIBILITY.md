## OpenCode Fleet configuration

Add an entry to `active_fleet.json` with `Provider: "opencode_cli"` and `Workspace` or `Worktree` set to an existing isolated checkout. Optional keys are `OpenCodePath`, `OpenCodeModel` (OpenCode’s `provider/model` form), `OpenCodeVariant`, `Timeout` (defaults to 600 seconds), and `OpenCodeAuto` (defaults to `true`). Sign in to providers with OpenCode itself; Fleet neither extracts nor copies those credentials. Multiple OpenCode and Codex workers may run concurrently; provider quota/authentication errors are returned as task failures.

Auto mode approves permission requests unless they have an explicit deny rule. It does not create an OS-level sandbox. Configure OpenCode permission rules and rely on Fleet’s isolated worktree for repository separation.

## Source and evidence policy

The supplied search-results paste is a candidate list, not evidence for product support or quota values. This map uses official product documentation where available, avoids volatile quota numbers, and marks unverified product claims explicitly. Personal-account applicability is limited to the entitlements stated for the user; this repository does not inspect or verify account credentials.
